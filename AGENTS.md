# Architecture decisions

- Generic edit/delete on lists goes through `src/components/shared/RecordActions.tsx` — one audited path for updates/deletes, RLS enforces rights.
- Deletions on key tables are captured by trigger `tg_capture_deleted` into `deleted_records`; restore only via `restore_deleted_record` (admin/coordinator) — recoverability without soft-delete columns everywhere.
- Accounting entries from CRM invoices/payments and validated payroll runs are generated by DB triggers as drafts (`source_type` crm_invoice/crm_payment) — accountant validates, avoids silent posting.
- Donor narrative reports are versioned in `donor_report_versions`; status transitions guarded by trigger — validated versions are immutable.
- Scheduled jobs call edge functions via pg_cron (e.g. `milestone-reminders` daily 07:30 UTC) — consistent with existing hr/crm daily jobs.
- Page-level phrase translations use `tr()` from `src/lib/phrases.ts`; I18nProvider remounts children on locale change — avoids threading hooks through every sub-component.
